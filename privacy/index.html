Politique de Confidentialité

Comment nous collectons, utilisons et protégeons vos données

Dernière mise à jour : 1er juin 2026  ·  Epargn+ — SOLUTIONS D'ÉPARGNE MODERNE  ·  Conakry, République de Guinée

1. Introduction

Epargn+ (« nous », « notre ») s'engage à protéger vos données personnelles. La présente Politique de Confidentialité décrit comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application mobile d'épargne.

2. Données collectées

2.1 Données d'identification

  • Numéro de téléphone mobile
  • Nom complet
  • Documents d'identité (dans le cadre du processus KYC)

2.2 Données financières

  • Solde de votre compte épargne
  • Historique des transactions (dépôts, retraits)
  • Objectifs d'épargne et leur progression

2.3 Données techniques

  • Identifiant de l'appareil (pour les notifications push)
  • Données biométriques locales (Face ID / Touch ID — jamais transmises à nos serveurs)
  • Adresse IP et données de connexion (journaux de sécurité)

2.4 Données de communication

  • Messages envoyés au support client

3. Utilisation des données

Vos données sont utilisées pour :

  • Créer et gérer votre compte épargne
  • Traiter vos transactions financières (dépôts, retraits)
  • Vérifier votre identité (conformité KYC/AML)
  • Vous envoyer des notifications relatives à votre compte
  • Améliorer nos services et détecter les fraudes
  • Respecter nos obligations légales et réglementaires

4. Base légale du traitement

Le traitement de vos données repose sur :

  • Exécution du contrat : traitement des transactions, gestion du compte
  • Obligation légale : conformité KYC, lutte contre le blanchiment d'argent
  • Intérêt légitime : sécurité, prévention des fraudes
  • Consentement : communications marketing (révocable à tout moment)

5. Partage des données

Nous ne vendons jamais vos données. Elles peuvent être partagées avec :

  • Opérateurs de paiement (Orange Money, MTN MoMo, Wave Guinée, Visa) pour traiter les transactions
  • Prestataires techniques hébergeant notre infrastructure (sous accord de confidentialité)
  • Autorités compétentes sur réquisition judiciaire ou obligation légale
  • Auditeurs financiers agréés dans le cadre de contrôles réglementaires

6. Sécurité des données

Nous mettons en œuvre :

  • Chiffrement TLS en transit et AES-256 au repos
  • Authentification à deux facteurs (OTP par SMS)
  • Stockage sécurisé des tokens via le Keychain iOS
  • Authentification biométrique locale (données jamais transmises)
  • Journaux d'accès et surveillance continue
  • Équipe sécurité dédiée avec audits périodiques

7. Conservation des données

  • Données de compte actif : durée de la relation contractuelle
  • Données de transactions : 10 ans (obligations légales financières)
  • Journaux de sécurité : 12 mois
  • Après fermeture de compte : anonymisation dans les 90 jours

Vous pouvez demander la suppression de vos données en contactant support@epargn.com (sous réserve des obligations légales de conservation).

8. Vos droits

Vous disposez des droits suivants :

  • Accès : consulter les données que nous détenons sur vous
  • Rectification : corriger des données inexactes
  • Suppression : demander l'effacement (sous réserve d'obligations légales)
  • Portabilité : recevoir vos données dans un format structuré
  • Opposition : vous opposer à certains traitements
  • Retrait du consentement : pour les communications marketing

Pour exercer ces droits : support@epargn.com

9. Biométrie (Face ID / Touch ID)

Les données biométriques sont traitées exclusivement sur votre appareil par iOS. Epargn+ ne reçoit qu'un signal de succès ou d'échec — jamais les données biométriques elles-mêmes. Vous pouvez désactiver cette fonctionnalité à tout moment dans les paramètres de l'application.

10. Notifications Push

Nous utilisons les notifications push pour vous informer de l'activité de votre compte (dépôts, retraits, rappels d'objectifs). Vous pouvez désactiver les notifications à tout moment dans les réglages iOS.

11. Modifications

Nous pouvons mettre à jour cette politique. En cas de changements significatifs, vous en serez informé par notification dans l'application au moins 30 jours avant leur entrée en vigueur.
