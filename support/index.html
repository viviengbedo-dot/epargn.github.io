Questions fréquentes

  • Comment déposer ? Ouvrir l'app → Dépôt → choisir Orange Money, MTN MoMo, Wave Guinée ou Visa → saisir le montant → confirmer.
  • Comment retirer ? Accueil → icône carte → Retrait → choisir le moyen → confirmer. Frais : 1%. Délai : immédiat à 24h.
  • Code PIN oublié ? Profil → Modifier le code PIN → vérification par OTP SMS.
  • Comment parrainer ? Profil → Parrainage → copier votre code. Bonus : 5 000 GNF par filleul qualifié.
  • Problème de transaction ? Écrire à support@epargn.com avec votre numéro de téléphone et la date.
